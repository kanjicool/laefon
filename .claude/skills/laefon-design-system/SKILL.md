# Laefon Design System

ที่มา: canvas ที่ตกลงกันแล้ว (claude.ai/artifact/DKBqTGp5ExvhG2eJ7W8zc2) โครงสร้าง skill ดัดแปลงจาก civic-design-system ของ tent

## หลักการ

1. **เวลาก่อน ตัวเลขทีหลัง** — ประโยคหลักคือ "ฝนน่าจะเริ่มตก 15:00 น." ตัวใหญ่สุดบนจอ % เป็นข้อมูลรอง
2. **ภาพเรดาร์เป็นชั้นเสริม** — ชั้นหลักของแผนที่คือโอกาสฝนรายตำบล
3. **ไม่สื่อด้วยสีอย่างเดียว** — ทุกสีฝนมีคำกำกับ
4. **บอกความไม่แน่นอนตรงๆ** — ข้อมูลจำลอง / ข้อมูลเก่า / โหมดย้อนดู ต้องมีแถบบอกเสมอ

| token | hex | ใช้ |

| `--foreground` | `#14212b` | ตัวอักษรหลัก |
| `--muted-foreground` | `#5a6b76` | ข้อความรอง (5.6:1 บนขาว) |

| `--selection` | `#e8590c` | ตำบลที่เลือก, "ตอนนี้" — ห้ามใช้กับอย่างอื่น |
| `--line` | `#06c755` | ปุ่มแชร์ LINE เท่านั้น |

## สเกลฝน (ห้ามเปลี่ยนโดยไม่แก้ `wording.ts`)

| ขั้น | คำ | เกณฑ์ `p_rain` | สี | ตัวอักษรบนสี |
|---|---|---|---|---|
| 0 | ไม่น่าตก | < 0.2 | `#eef1f3` | เข้ม |
| 1 | อาจมีฝน | 0.2–0.45 | `#c5def0` | เข้ม |
| 2 | น่าจะตก | 0.45–0.7 | `#7fb4dd` | เข้ม |
| 3 | ฝนตกแน่ | ≥ 0.7 | `#2f6fb0` | ขาว |
| 4 | อาจหนัก | `p_heavy` ≥ 0.5 | `#5b3c9e` | ขาว |

"เริ่มตก" = step แรกที่ `p_rain ≥ 0.45` (ขั้น 2 ขึ้นไป)

สีภาพเรดาร์ (mm/h): 0.5 `#a9d3ef` · 2 `#5fa8e0` · 5 `#2f6fb0` · 10 `#4b3fa3` · 20 `#8e3ba8` — legend ใช้คำ "เล็กน้อย / ปานกลาง / หนัก / หนักมาก / รุนแรง" ไม่ใช้ dBZ

## ตัวอักษร

IBM Plex Sans Thai Looped (โหลดใน `app.html`) · ตัวเลขเวลา `tabular-nums`
คำตอบหลัก 44–52px/700 · หัวข้อ 24–34px/700 · เนื้อหา 16–17px · ข้อมูลประกอบ 12–14px
มือถือ body ≥ 16px · จุดกด ≥ 44px

## Layout

- desktop: header 64px → แถบเตือน → แถว [panel ซ้าย 380–420px | แผนที่เต็มที่เหลือ] แถบเวลาลอยล่างแผนที่ legend มุมซ้ายบน สลับชั้นข้อมูลมุมขวาบน
- มือถือ (< lg): แผนที่ด้านบน panel ต่อด้านล่าง
- การ์ดคำตอบ: พื้น `#eaf2f8` มุม 16px ไอคอนเมฆฝนในกล่อง `#2f6fb0`

## สถานะที่ต้องมี

กำลังโหลด (skeleton ไม่ใช่ spinner) · ข้อมูลเก่า > 30 นาที (แถบเหลือง `#fff4d6`) · `is_mock` (แถบเหลืองถาวร) · โหมดย้อนดู (แถบฟ้า `#e6f1f4`) · ไม่มีฝนทั้งจังหวัด · GPS ไม่อนุญาต · โหลดไม่ได้ + ปุ่มลองใหม่ · footer "ไม่ใช่ประกาศทางการของกรมอุตุนิยมวิทยา · สายด่วน 1182"

## ข้อห้าม

- ห้าม gradient พื้นหลัง, emoji แทนไอคอน (ใช้ Lucide), การ์ดขอบซ้ายสี
- ห้าม rainbow scale แบบภาพเรดาร์ดั้งเดิม
- ห้ามแสดงตัวเลขผลโมเดลที่ไม่ได้มาจาก `metrics.json`
- ห้ามใช้ชื่อ/โลโก้กรมอุตุนิยมวิทยาจนกว่าจะได้รับอนุญาต
